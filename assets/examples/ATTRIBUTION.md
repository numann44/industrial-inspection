# Example image attribution

The metal-nut examples are unmodified images from [MVTec AD](https://www.mvtec.com/research-teaching/datasets/mvtec-ad), MVTec Software GmbH, distributed under [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). Each original category/test/defect/filename is recorded in `artifacts/models.json`. Runtime activation overlays are adaptations and retain the dataset license. Images are used for a noncommercial educational inspection demonstration.
