# Demo screenshot attribution

`live-study-v0.1.0.png` is an actual screenshot of the hosted v0.1.0 app's measured-performance panel, captured on October 4, 2026. It shows the selected KolektorSDD2 model's reported counts, metrics and limitations; it contains no dataset image. The measurements derive from KolektorSDD2, Kolektor Group; Jakob Božič, Domen Tabernik and Danijel Skočaj, *Computers in Industry* (2021). See the [dataset source](https://www.vicos.si/resources/kolektorsdd2/) and [controlled report](../results/CONTROLLED_STUDY.md). No app interface or result was generated for the screenshot.

`live-inspection.png` and `live-demo.png` are actual screenshots of the project's hosted Streamlit app, captured on October 2, 2026. They show the exploratory pilot; they are not simulated model results.

The activation overlay is a model-generated adaptation.
